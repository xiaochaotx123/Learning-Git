#### Linux是什么
Linux通常指一个开源的操作系统内核，也常被用来泛指基于这个内核构建的整套操作系统。
- 严格定义：Linux是操作系统内核，由Linus Torvalds在1991年创建，负责管理CPU、内存、硬盘、网络等硬件资源，并为程序提供运行环境
- 日常用语：人们说"Linux系统"，通常指的是Linux发行版，比如Ubuntu、Debian、Fedora、CentOS、Arch Linux等，它们 = Linux 内核 + GNU 工具 + 图形界面 + 软件包管理器 + 各种应用。

#### 官方Git的核心实现主要是用C语言写的
严格来说，Git不是100%的纯C。它的核心部分，比如对象数据库、索引、提交历史、合并、diff、传输协议等，主要是C  
但项目里也有一些辅助脚本和工具，历史上和现在都可能用到：Shell、Perl、Python、少量其他语言
