#### git -v
git -v 查询当前安装的Git版本
- git：这是主命令
- -v：这是--version的简写形式。在很多命令行工具里，-v通常都是version的缩写（有些软件里-v表示verbose，即"详细输出"）

#### git config --list
git config --list 列出当前Git的所有配置信息


#### Git可以安装在Windows、macOS、Linux、Raspberry Pi操作系统上
- Windows是微软公司开发的闭源商业操作系统。全球用户最多，桌面市场占有率极高。最大的优势是兼容性极强，无论是办公软件、大型游戏还是各类专业工具，都能在上面运行。图形界面非常成熟。
- macOS苹果公司专为自家 Mac 电脑（MacBook、iMac）开发的操作系统。基于 Unix 内核开发（这一点极其重要）。它的界面美观、软硬件结合极其丝滑，是很多设计师、视频剪辑师以及程序员的首选。由于它是基于 Unix 的，它的自带终端（Terminal）和 Linux 非常像。
- Linux是一个开源、免费的操作系统内核。极度稳定、安全、高度可定制。它很少作为普通人日常娱乐的系统，但它是全球服务器、超级计算机和云计算领域的绝对霸主。世界上绝大多数的网站服务器跑的都是 Linux。
- Raspberry Pi其实是一块“信用卡大小的微型电脑主板”（硬件），而不是操作系统本身。它通常运行的是基于 Linux 的系统，官方系统叫做 Raspberry Pi OS。价格便宜（几百块人民币）、功耗极低（可以一直开着）、体积小。常被用来做智能家居中枢、微型服务器、机器人控制器、或者用来教小孩子学编程。
